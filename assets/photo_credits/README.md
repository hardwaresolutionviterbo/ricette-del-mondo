# Sistema foto — Ricette del Mondo V6

La V6 usa questa priorità per le immagini:

1. foto locali già verificate;
2. eventuale `imageUrl` esplicito della ricetta;
3. Openverse con licenze potenzialmente riutilizzabili;
4. Wikimedia Commons;
5. icona ufficiale dell'app come fallback quando non è stata trovata una foto sufficientemente attendibile.

Le immagini esterne non vengono considerate automaticamente "verificate": l'app applica filtri automatici e conserva l'URL associato alla ricetta. Per una distribuzione commerciale, la licenza della singola opera deve essere controllata prima della pubblicazione definitiva.
